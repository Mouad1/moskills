# /learn

Manual trigger for the `learn` skill.

Run it after a correction, a found root cause, or a rejected review to capture
the lesson into `tasks/lessons.md` with a prevention rule. The skill also
checks whether the lesson has repeated enough to be promoted into the project
`CLAUDE.md` or into a reusable moskills rule.

The skill also fires automatically when the user corrects the agent or when
`/diagnose` confirms a root cause.
